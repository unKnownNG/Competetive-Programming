In particular, $$$\operatorname{mex}_1(\mathcal{S})$$$ is the usual $$$\operatorname{mex}$$$$$$^{\text{∗}}$$$ of $$$\mathcal{S}$$$.</p><p>For example: </p><ul> <li> $$$\operatorname{mex}_1(\{0, 1, 1, 2\}) = 3$$$; </li><li> $$$\operatorname{mex}_2(\{0, 0, 1, 1, 1, 3\}) = 2$$$; </li><li> $$$\operatorname{mex}_2(\{0, 1, 1, 2\}) = 0$$$; </li><li> $$$\operatorname{mex}_2(\{0, 0, 1, 2\}) = 1$$$. </li></ul><p>You are given an <span class="tex-font-style-bf">even</span> integer $$$n$$$, a positive integer $$$k$$$, and $$$n$$$ cards. The integer $$$a_i$$$ is written on the $$$i$$$-th card.</p><p>Alice and Bob play the following game with these cards. Alice moves first, and the players alternate turns. On each turn, the current player takes any one of the remaining cards. The game ends when all $$$n$$$ cards have been taken, so each player ends up with exactly $$$\dfrac{n}{2}$$$ cards.</p><p>Let $$$\mathcal{A}$$$ be the multiset of integers written on Alice's cards, and let $$$\mathcal{B}$$$ be the multiset of integers written on Bob's cards. Alice wins if $$$\operatorname{mex}_k(\mathcal{A}) \ne \operatorname{mex}_k(\mathcal{B})$$$, and Bob wins otherwise.</p><p>Determine whether Alice wins if both players play optimally.</p><div class="statement-footnote"><p>$$$^{\text{∗}}$$$The minimum excluded (MEX) of a collection of integers $$$c_1, c_2, \ldots, c_m$$$ is defined as the smallest non-negative integer $$$x$$$ which does not occur in the collection $$$c$$$.</p></div></div><div class="input-specification"><div class="section-title">Input</div><p>Each test contains multiple test cases.
