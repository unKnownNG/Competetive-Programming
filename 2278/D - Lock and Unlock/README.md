## Problem Statement

<div class="header"><div class="title">D. Lock and Unlock</div><div class="time-limit"><div class="property-title">time limit per test</div>2 seconds</div><div class="memory-limit"><div class="property-title">memory limit per test</div>256 megabytes</div><div class="input-file input-standard"><div class="property-title">input</div>standard input</div><div class="output-file output-standard"><div class="property-title">output</div>standard output</div></div><div><p>You are given an integer array $$$[a_1, a_2, \ldots, a_n]$$$. Initially, all the elements are unlocked.</p><p>You may perform the following operation on array $$$a$$$ any number of times (possibly zero): </p><ol> <li> Choose an integer $$$k$$$ ($$$1 \le k \le n$$$) and choose exactly $$$k$$$ distinct indices. The elements at these indices are <span class="tex-font-style-bf">locked</span> for the current operation. This step incurs a cost equal to $$$k$$$.<p> </p></li><li> Choose one of the following two actions:<p> </p><ul> <li> Increase <span class="tex-font-style-bf">every unlocked</span> element by $$$1$$$; </li><li> Decrease <span class="tex-font-style-bf">every unlocked</span> element by $$$1$$$. </li></ul> This step does not incur any additional cost.<p> </p></li><li> Unlock all the elements. This step does not incur any additional cost. </li></ol><p>The total cost is equal to the sum of the individual costs over all the operations performed.</p><p>Determine the minimum possible total cost to make all the elements of the array $$$a$$$ equal. Furthermore, among all the ways to achieve this minimum possible total cost, find the minimum number of operations required.</p></div><div class="input-specification"><div class="section-title">Input</div><p>The first line of the input contains a single integer $$$t$$$ ($$$1 \le t \le 2 \cdot 10^4$$$) — the number of test cases. The description of each test case follows.</p><p>The first line of each test case contains a single integer $$$n$$$ ($$$2 \le n \le 2 \cdot 10^5$$$) — the length of the array $$$a$$$.</p><p>The second line of each test case contains $$$n$$$ integers $$$a_1, a_2, \dots, a_n$$$ ($$$-10^9 \le a_i \le 10^9$$$) — the elements of the array $$$a$$$.</p><p>It is guaranteed that the sum of $$$n$$$ over all the test cases does not exceed $$$2 \cdot 10^5$$$.</p></div><div class="output-specification"><div class="section-title">Output</div><p>For each test case, print two space-separated integers on a new line — the minimum possible total cost to make all the elements equal, and the minimum number of operations required to make all the elements equal with the minimum possible total cost.</p></div><div
