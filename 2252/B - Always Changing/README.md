Always Changing</div><div class="time-limit"><div class="property-title">time limit per test</div>1.5 seconds</div><div class="memory-limit"><div class="property-title">memory limit per test</div>256 megabytes</div><div class="input-file input-standard"><div class="property-title">input</div>standard input</div><div class="output-file output-standard"><div class="property-title">output</div>standard output</div></div><div><p>You are given a binary string $$$s$$$ of length $$$n$$$. </p><p>A string is called alternating if no two adjacent characters are the same. For example, <span class="tex-font-style-tt">0101</span>, <span class="tex-font-style-tt">1</span>, and <span class="tex-font-style-tt">01</span> are alternating, but <span class="tex-font-style-tt">0110</span> is not.</p><p>You want to transform $$$s$$$ into an alternating string by performing the following operation any number of times (possibly zero): </p><ul> <li> Choose any character currently in the string and delete it. </li></ul><p>However, your sequence of operations must follow a rule: the characters you delete must strictly alternate. This means if the last character you deleted was <span class="tex-font-style-tt">0</span>, the next character you delete must be <span class="tex-font-style-tt">1</span>, and vice versa. Your very first deleted character can be either <span class="tex-font-style-tt">0</span> or <span class="tex-font-style-tt">1</span>.</p><p>Find the minimum number of operations required to make $$$s$$$ an alternating string. If it is impossible to achieve this, output $$$-1$$$.</p></div><div class="input-specification"><div class="section-title">Input</div><p>Each test contains multiple test cases. We deleted three <span class="tex-font-style-tt">1</span>s and two <span class="tex-font-style-tt">0</span>s, which takes $$$5$$$ operations.</p></div>
