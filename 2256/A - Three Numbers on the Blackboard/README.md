## Problem Statement

<div class="header"><div class="title">A. Three Numbers on the Blackboard</div><div class="time-limit"><div class="property-title">time limit per test</div>1 second</div><div class="memory-limit"><div class="property-title">memory limit per test</div>256 megabytes</div><div class="input-file input-standard"><div class="property-title">input</div>standard input</div><div class="output-file output-standard"><div class="property-title">output</div>standard output</div></div><div><p>Rain is falling outside the Fairy Warehouse, so Chtholly, Nephren, and Ithea spend the afternoon playing a game in the common room.</p><p>Ithea writes three non-negative integers $$$a$$$, $$$b$$$, and $$$c$$$ on the blackboard. </p><p>Chtholly may perform the following operation an arbitrary number of times (possibly zero):</p><ul> <li> Choose one of the three current integers and replace it with the sum of the other two current integers. The other two integers remain unchanged. </li></ul><p>For example, starting from $$$(3,5,11)$$$, she can replace $$$11$$$ with $$$3+5$$$, obtaining $$$(3,5,8)$$$.</p><p>Nephren wants to know the minimum range$$$^{\text{∗}}$$$ of the three integers that Chtholly can obtain. Help her find it!</p><div class="statement-footnote"><p>$$$^{\text{∗}}$$$The range of a non-empty finite collection of numbers is defined as its maximum value minus its minimum value. In particular, the range of three numbers $$$x$$$, $$$y$$$, and $$$z$$$ is $$$\max(x,y,z)-\min(x,y,z)$$$.</p></div></div><div class="input-specification"><div class="section-title">Input</div><p>Each test contains multiple test cases. The first line contains the number of test cases $$$t$$$ ($$$1 \le t \le 100$$$). The description of the test cases follows.</p><p>The only line of each test case contains three integers $$$a$$$, $$$b$$$, and $$$c$$$ ($$$0 \le a,b,c \le 10^9$$$) — the integers initially written on the blackboard.</p></div><div class="output-specification"><div class="section-title">Output</div><p>For each test case, output a single integer — the minimum possible range of the three
