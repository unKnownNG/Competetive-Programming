Mr. Rumb can program a machine to perform the following operation <span class="tex-font-style-bf">exactly once</span>:</p><ul> <li> choose an integer $$$m$$$ ($$$1 \le m \le n$$$) and indices $$$i_1  \lt  i_2  \lt  \ldots  \lt  i_m$$$; </li><li> reverse the elements of $$$p$$$ at the chosen indices.
