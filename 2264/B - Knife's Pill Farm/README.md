<div class="header"><div class="title">B. His goal is to farm pill emoji reactions. Unfortunately, the channel's pill-farming bot uses an unnecessarily elaborate scoring rule.</p><p>The drafts have absurdity ratings $$$a_1, a_2, \ldots, a_n$$$, which may be negative. Mr. Knife must publish exactly $$$m$$$ drafts in their original order. Their ratings form a subsequence$$$^{\text{∗}}$$$ $$$b$$$ of $$$a$$$ with length $$$m$$$.</p><p>His <span class="tex-font-style-it">pill score</span> starts at $$$0$$$. When he publishes the $$$i$$$-th chosen draft, the bot changes his score by $$$i \cdot (b_i - b_{i-1})$$$, where $$$b_0 = 0$$$. A negative change deducts points, and the score is allowed to become negative. Thus, his final pill score is $$$$$$ \sum_{i = 1}^{m} i \cdot (b_i - b_{i - 1}). $$$$$$</p><p>What is the maximum pill score Mr. Knife can obtain by choosing which drafts to publish?</p><div class="statement-footnote"><p>$$$^{\text{∗}}$$$A sequence $$$a$$$ is a subsequence of a sequence $$$b$$$ if $$$a$$$ can be obtained from $$$b$$$ by the deletion of several (possibly, zero or all) elements from arbitrary positions.</p></div></div><div class="input-specification"><div class="section-title">Input</div><p>Each test contains multiple test cases. The first line contains the number of test cases $$$t$$$ ($$$1 \le t \le 10^4$$$). The description of the test cases follows.</p><p>The first line of each test case contains two integers $$$n$$$ and $$$m$$$ ($$$1 \le m \le n \le 2 \cdot 10^5$$$) — the number of drafts and the number of posts Mr. Knife must publish.</p><p>The second line contains $$$n$$$ integers $$$a_1, a_2, \ldots, a_n$$$ ($$$-10^7 \le a_i \le 10^7$$$) — the absurdity ratings of the drafts.</p><p>It is guaranteed that the sum of $$$n$$$ over all test cases does not exceed $$$2 \cdot 10^5$$$.</p></div><div class="output-specification"><div class="section-title">Output</div><p>For each test case, print one integer — the maximum pill score Mr. Knife can obtain by publishing exactly $$$m$$$ drafts in their original order.</p></div><div class="sample-tests"><div
