Such a move is allowed only if at least one of the following conditions holds:</p><ul> <li> exactly one element is removed; </li><li> the sum of the removed elements is even. </li></ul><p>A player who cannot make a move loses. In other words, the player who faces an empty array loses.</p><p>Determine which player has a winning strategy.</p></div><div class="input-specification"><div class="section-title">Input</div><p>Each test contains multiple test cases.
