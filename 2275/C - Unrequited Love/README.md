The instrument has $$$n$$$ keys, giving $$$a_1, a_2, \ldots, a_n$$$ <span class="tex-font-style-it">units of audience love</span>.</p><p>Playing one note at a time is boring, so K1o0n learned a single technique — <span class="tex-font-style-it">a triad</span>: three keys with one key between each pair, pressed simultaneously. Therefore, K1o0n wants to choose exactly two different triads that <span class="tex-font-style-bf">do not</span> share any keys.
